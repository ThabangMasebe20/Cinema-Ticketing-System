# Cinema Ticketing System

A networked client-server cinema ticketing application built in Python. 
The server manages a SQLite database of movies and sales, while the 
Tkinter client provides a GUI for browsing movies and purchasing tickets.

## Features
- TCP socket communication between client and server
- Multi-threaded server handling concurrent clients
- SQLite database for movie and sales persistence
- GUI client built with Tkinter
- Auto-generated receipt on ticket purchase

## Tech Stack
- Python
- SQLite3
- Tkinter
- Socket Programming
- Threading

## How to Run
1. Start the server: `python server.py`
2. Run the client: `python client.py`
